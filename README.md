Job Market Analysis Project

Goal
Analyze demand for data analyst skills and salaries using real job postings data.

Dataset
Global job postings dataset with salary information, job descriptions, and locations.

Main findings
Excel and SQL appear in over half of job postings.
Python appears in about one third of postings.
Visualization tools Tableau and Power BI show strong demand.
Median hourly salary about 33 USD.
Median yearly salary about 96k USD.

Files in project
notebooks contains analysis notebook
data processed contains cleaned dataset
reports figures contains charts

Tools
Python pandas matplotlib scikit learn Jupyter.

Dataset note
Raw dataset is not included due to size limits.
You can download similar datasets from Kaggle job postings datasets.
